# SATCAP reproducibility release v1.0.0

This release corresponds to the SATCAP submission package.

## Included

- Results-only workflow and 29 regression/integrity checks.
- Primary fastStorage scripts and reported outputs.
- Executed GWA-T-12 Rnd second-panel and coefficient-transfer outputs.
- Multi-resource, DDSketch, OpenTelemetry payload, and controller analyses.
- Vector figures, provenance records, hashes, and data-license documentation.

## Excluded

- Raw Bitbrains provider traces and large derived caches.
- Cover letter, journal submission forms, and other editorial files.
- Unexecuted Kubernetes/OpenStack prototypes.
- The manuscript PDF; the repository is a software/reproducibility release, not a preprint deposit.
